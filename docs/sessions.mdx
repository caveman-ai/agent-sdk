A Session is one continuous conversation with one append-only event log. Use `cave.sessions.create()` for multi-turn interactions, live event streaming, custom tool callbacks, approvals, and interrupts.

## Stream events and send follow-ups

```ts
import { Caveman } from "@caveman-ai/agent";

const cave = new Caveman();
const session = await cave.sessions.create({
  agent: "builder",
  task: "Fix the flaky retry test",
  cwd: ".",
});

for await (const event of session.events()) {
  console.log(event.seq, event.type, event.data);
}

const first = await session.next();
const followUp = await session.send("Also add a regression test for 429 responses.");
await session.close();
```

## Approvals and questions

When an agent calls a custom tool, requests approval, or asks a question, the session emits a `requires_action` event carrying an `Ask`:

- **`kind: "tool"`**: answered automatically by the handler passed to `tool()`. If the tool declares a `gate` policy (or the session/agent passes `gate` / `gateProvider`), the SDK enforces Caveman Gate fail-closed before executing the custom tool handler.
- **`kind: "approval"`**: answered by `canUseTool` for runtime-owned actions (such as shell or filesystem operations). Denied by default when no handler is provided.
- **`kind: "question"`**: answered by `onQuestion`. When omitted, the agent decides and states its assumption.

Pass `gate` and/or `gateProvider` (for example `createCloudGateProvider` or `createMemoryGateProvider`) on `cave.sessions.create()` to approve SDK-executed custom tools with per-session rule overrides taking precedence over per-tool and agent-level gate defaults.

## Cheap-first escalation with checks

```ts
const result = await cave.run({
  agent: "builder",
  task: "Fix the failing parser test",
  model: "fast",
  check: "pnpm test",
  escalate: ["base", "frontier"],
  budget: { usd: 2 },
});
```

If `check` exits non-zero (or returns a failure string from a function), the SDK passes the failure output to the next model in `escalate` and stops immediately if `budget.usd` is reached.
