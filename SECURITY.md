# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately to `security@caveman.so` rather
than opening a public GitHub issue. Include the affected package (`@caveman-ai/agent`,
`@caveman-ai/harness`, `@caveman-ai/protocol`, `@caveman-ai/evals`, `@caveman-ai/react`,
or `caveman-evals`), version, reproduction steps, and impact (especially sandbox
isolation, env allowlist leaks, or SSRF bypasses in webhook graders).

We acknowledge reports within 2 business days and coordinate disclosure once a
fix is released.
